\# Bomberman Multiplayer Game



A real-time multiplayer Bomberman clone featuring a C# ASP.NET Core SignalR server and a Java Swing client.



\## Requirements

\* .NET 8.0 SDK or higher

\* Java Development Kit (JDK 17+)



\## Running the Server (C#)

```bash

cd Server

dotnet run

```

Server starts on `http://localhost:5000`.



\## Running the Client (Java)

1\. Open the `Client` directory in your Java IDE (IntelliJ / Eclipse / VS Code).

2\. Run `Main.java`.
